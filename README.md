# APY Converter

A small Python command-line calculator for translating quoted APY into comparable daily rates and realized returns under different compounding conventions.

## What it does

- Takes an APY, principal amount, and investment horizon as inputs.
- Handles both continuous and periodic compounding assumptions.
- Converts APY into an implied annual rate and a simple daily-rate equivalent.
- Computes the resulting value over the selected holding period.

## Technical focus

**Python, financial mathematics, compounding conventions**

This project was built as a compact utility for checking how quoted annual yields translate into shorter-horizon returns when compounding assumptions differ.
